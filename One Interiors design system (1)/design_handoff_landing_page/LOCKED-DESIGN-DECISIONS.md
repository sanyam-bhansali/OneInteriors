# One Interiors — locked design decisions

## Palette — "Tactile Assurance" (locked)

| Token | Value | Use |
| --- | --- | --- |
| Raw Silk | `#EAE6DF` | page background |
| Alabaster | `#FCFCFA` | cards, tables, quote documents |
| Deep Espresso | `#2C2624` | all primary type, dark surfaces |
| Terracotta | `#C0613C` | high-intent actions only (Request quote, Quote me), and gap/attention flags |
| Muted Sage | `#839073` | verification, match scores, "better spec" marks |
| Hairline | `#DBD5CB` | rules and borders |
| Secondary ink | `#6B615C` | body copy on light |
| Warm card on glass | `rgba(247,242,234,.76)` + `blur(18px)` | snapshot cards inside glass frames |

Inline-style token block used on every artboard root:

```
--bg:#EAE6DF;--card:#FCFCFA;--ink:#2C2624;--ink2:#6B615C;--acc:#C0613C;--sec:#839073;--line:#DBD5CB
```

Palette A (Beige/Charcoal/Deep Terracotta/Olive) is **rejected** — do not build new work on it.

## Typography (locked)

- **Instrument Serif** — headlines, product names, pull quotes. Tight tracking (`-.015em`) at display sizes.
- **Instrument Sans** — body, UI, buttons. 13.5–19px.
- **IBM Plex Mono** — evidence and metadata: labels, uppercase `.14–.22em` tracked eyebrows, money, quantities, specs, counters, scores. Never for body copy.

## Section language (locked)

Squared corners everywhere **except** glass surfaces and elements inside them, which are curved (26px frames, 12–18px inner). Mono eyebrow → serif heading → sans body. Money and specs always mono.

## How-it-works section — 4a is the locked structure

Pinned spine: steps list on the **left** (scroll-driven, click to centre), a **frosted-glass frame over a project photograph on the right** holding one product snapshot per step. Snapshots are real software views, not generic infographics:

1. **OneQuiz** — "Your brief so far" with answered facts and the live *n studios still match* counter.
2. **OneMatch** — who fits: score rings, work thumbnail, reason matched, "nobody can pay to sit higher".
3. **OneQuote** — line items each carrying quantity and spec. The first quote is **generated by our system** from the studio's own fed rate card in about three seconds — no studio is asked, nobody is phoned. Never describe this as requesting a quote.
4. **OneCompare** — quotes side by side **and** the materials behind them (carcass, shutter, hardware).
5. **OneExpert** — a personal architect assigned for the whole journey, verifying every step.

## Content rules

- Studio names in marketing surfaces are **invented**: Teakline Studio, Chitra & Co., Maya Workshop. Never Hauspire / Urbanline / real partner names.
- Figures come from the repo where they exist (₹5.95 L–₹27.2 L range, 12 verification checks, 68 briefs).
- Photography is licensed stock standing in for real project work and must be replaced before launch; hero "films" are placeholders awaiting real MP4s.
