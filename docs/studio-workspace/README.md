# One Interiors — studio project workspace hand-off

Everything Claude Code needs to add the studio project workspace to the
existing One Interiors app.

## What's inside

| Path | What it is |
|---|---|
| `STUDIO-WORKSPACE-BUILD.md` | The feature brief: decisions, roles, data model, what the customer may see, six phases with "done when" tests, open decisions. **Start here.** |
| `designs/README.md` | How to read the screen files, and which screen belongs to which phase |
| `designs/studio/` | The 8 studio screens (site mode on phone, office on desktop) |
| `designs/customer/` | The customer app screens, including the ones the studio side feeds |
| `designs/canvas.json` | The design canvas index: screen titles and designer notes |

## How to use it

1. Copy this folder into the repo as `docs/studio-workspace/`.
2. In Claude Code, from `C:\Sanyam\OneInteriors`:

   > Read `docs/studio-workspace/STUDIO-WORKSPACE-BUILD.md` and
   > `docs/studio-workspace/designs/README.md`. Then read the code that
   > Phase 1 touches and give me a plan for Phase 1. Don't write code until
   > I approve.

3. Approve one phase at a time.
