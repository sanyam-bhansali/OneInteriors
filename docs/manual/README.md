# The studio app manual

How to use the studio app (studio.oneinteriors.in), one file per role.
Written for the people who use it every day, in plain words.

| Who you are | Read |
| --- | --- |
| Sales rep or sales head | [sales.md](sales.md) |
| Designer | to come (`design.md`) |
| Project manager and site | to come (`projects.md`) |
| Accounts | to come (`accounts.md`) |
| Owner and admin | to come (`admin.md`) |

## How these files are written

- One section per feature. Each section says what the feature is for, how to use it step by step, who can do what, and the common mistakes.
- Short sentences. Button names in **bold**, exactly as they show in the app.
- When the app changes, change the section in the same pull request.
